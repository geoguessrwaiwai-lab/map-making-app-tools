# Map Making App Tools

[Map Making App](https://map-making.app/)を使いやすくするためのChrome拡張機能です。

以下の複数の機能を含んでいます。

- マップ編集画面で、左右50%ずつに固定されている画面幅を、25%〜75%の範囲で自由に変更できます
- マップ編集画面で、「ぽちぽちモード」を選択できます。ぽちぽちモードをONにすると、選んだロケーションは次に別のロケーションを選んだ際に自動で選択を削除され、既存のマップの選択地点を汚さずに次々と地点確認ができるようになります。
- ホーム画面のUIを刷新し、フォルダ・お気に入り・タグ・国チップつきのカード表示に切り替えられます
- マップ編集画面のTagsパネルで、タグをグループにまとめて絞り込めます

それぞれの機能は拡張機能の設定画面からON/OFFできるため、気に入った機能だけを使用できます。デフォルトでは全ての機能がONになっています。

## インストール

- [Chrome ウェブストアからインストール](https://chromewebstore.google.com/detail/flhepjgbbcielemfkkkfimcfhgfomofj?utm_source=item-share-cb)

## 機能

### 画面幅の変更

マップ編集画面の中央に境界線が表示され、ドラッグすると左右の画面幅を25%〜75%の範囲で変更できます。ウィンドウサイズや画面遷移が変わっても、境界線の位置とレイアウトは追従します。

### ぽちぽちモード

画面右上のトグルでON／OFFを切り替えるモードです。ONの状態で新しいロケーションを選ぶと、その次にロケーションを選び直した時点で、直前に新しく選んだロケーションを自動的に削除します。すでに保存済みのロケーションや、Save・Closeで確定させたロケーションは削除対象になりません。

ぽちぽちモードのON／OFFの状態はマップごとに記憶されます。そのため、ぽちぽちモードを常時ONにしておきたいマップ、常時OFFにしておきたいマップを自然と区別しながら利用できます。

### ホーム画面

トップページのマップ一覧を、フォルダで分類したカード表示に切り替えます。

- フォルダの追加・名称変更・削除、フォルダ・マップカードのドラッグ並び替え
- マップのお気に入り登録、国チップ、タグ（複数付与可）による整理
- カードの「⋯」メニューから、名前・フォルダ・タグを編集
- 表示言語（日本語／英語）の切り替え、ロケーション数・国チップアイコンの表示切り替え
- いつでもフッターのボタンから、元のネイティブな一覧表示に戻せます

### タググループ

マップ編集画面のTagsパネルに、タグをまとめるグループを追加します。元の一覧の見た目は変えずに、グループ単位でタグを絞り込んで表示できます。

- グループの作成・編集・削除と、常時表示の「未分類」フィルター
- 部分一致検索と一括選択つきのタグ紐づけモーダル、既存タグをグループチップへドラッグ&ドロップして紐づける操作
- グループごとのチェックボックスで、そのグループのタグをMap Making App本来の選択状態へ一括で切り替え（解除も可能）
- 一覧から消えたタグは、2回続けて見当たらないことを確認してから登録簿とグループ所属から自動的に外れます

グループの定義はマップURL単位で保存されます。

## 拡張機能の設定

Chromeのアドレスバーに `chrome://extensions/` と入力し、インストールされている拡張機能の一覧を開きます。

「Map Making App Tools」の「詳細」から「拡張機能のオプション」を開くと、次を設定できます。

- 画面幅調整を使用する
- ぽちぽちモードを使用する
- 表示言語（日本語／English）
- フォルダビューを使用する
- フォルダビューのマップ名を別タブで開く（OFFで同じタブ）
- フォルダビューのマップカードにロケーション数を表示する
- フォルダビューのマップカードに国チップアイコンを表示する
- タググループを使用する
- URL別設定がないマップで、ぽちぽちモードのONをデフォルトにする
- 保存済みのURL別ON／OFFを一覧から変更する
- URLの部分一致検索で設定を絞り込む
- 個別設定を全体デフォルトへ戻す、または確認画面からURL別設定をすべて削除する

Map Making App上でトグルを切り替えたURLでは、そのURL専用のON／OFFが全体デフォルトより優先されます。機能別設定の変更は、開いているMap Making Appにも即座に反映されます。

### タググループ

Map Making Appの「Tags」パネル（`.tag-manager`）の見た目・構造は変更せず、タグをグループ単位で絞り込むためのツールバーだけを追加します。

- Tagsパネル内の一覧の上に、グループ名のチップが並ぶ小さなツールバーを追加する
- ツールバーには常に「すべて」「未分類 (件数)」のチップを表示する。「未分類」はどのグループにも属していないタグの絞り込み用で、削除も名前変更もできない
- 「＋ グループを追加」でグループ名だけを入力して作成する（タグの紐づけはここでは行わない）
- 各グループのチップには`グループ名 (件数)`のように所属タグ数を表示する
- 各グループの✎から、グループ名の変更と所属タグの紐づけを1つのモーダルでまとめて編集できる
  - タグのチェックボックス一覧では、他のグループに未所属のタグを優先して上に表示し、既に他グループへ所属しているタグはグループ名を添えて薄く表示する
  - タグ名の部分一致で絞り込める検索欄を用意
  - 「表示中のタグをまとめて選択／解除」のチェックボックスで、検索結果に対して一括紐づけ・解除ができる
- 各グループの✎の左隣にあるチェックボックスは、タグの紐づけ（グループ所属）自体は変更せず、Map Making App本来の「タグをクリックして選択状態（外枠が白くなる`is-selected`状態）にする」操作を、そのグループに属するタグ全てに対して代行する。ONでまだ選択されていない分もまとめて選択状態にし、OFFで選択されている分をまとめて選択解除する
- 各グループの×で削除できる（所属タグは未分類に戻る）
- 元の一覧の既存タグ（ドラッグ可能な要素）を、ツールバーのグループチップまたは「未分類」チップへドラッグ&ドロップして紐づけできる。元の一覧自体のドラッグ操作（並び替えなど）は横取りしない
- 名前入力・タグ選択・削除確認は、OSの`prompt`/`confirm`ではなく拡張機能側で組んだモーダルUIで行う
- グループ名のチップをクリックすると、そのグループに含まれないタグを元の一覧から一時的に非表示にする（もう一度「すべて」を押すと解除）
- タグの表示・非表示はCSSクラスの切り替えだけで行い、一覧の要素そのものは移動・複製しない
- グループ定義と所属タグは、マップURLごとに`chrome.storage.local`へ保存する
- タグの実データ（名前・色・並び順・件数）はMap Making App側が管理したままで、この機能からは変更しない。タグの追加・編集・削除は、引き続き元の一覧から行う
- タグの識別は表示名（件数バッジを除いたテキスト）で行う。同名タグが複数存在する場合はグループ所属を共有し、絞り込み表示や✎横の一括選択チェックボックスは同名の全タグへまとめて適用される
- Tagsパネルの一覧に新しく現れたタグは自動的に未分類として登録される
- 一覧から消えたタグ（削除ボタンでの削除、紐づくロケーションが0件になった際の自動削除のどちらも含む）は、Tagsパネルの検索欄が空、かつ2回連続で一覧に見当たらないことを確認できた場合にだけ、登録簿とグループの所属から自動的に取り除かれる（グループの件数表示にも反映される）。検索で絞り込んでいる間や、タブを開いた直後などタグがまだ読み込み中で一覧が空の間は誤って取り除かないようにしている

## セキュリティとプライバシー

- 使用する権限は`storage`のみで、外部サイトへの通信・Cookie・分析ツールは一切使用しません
- 拡張機能が保存するのはURL別のぽちぽちモードON／OFF、フォルダビューのフォルダ構成・お気に入り・国チップ・タグ・表示言語、タググループの定義（グループ名とタグの所属）といった設定情報だけです
- 選択履歴や地点情報、マップの内容そのものを外部に記録・保存・送信することはありません

詳しくは[プライバシーポリシー](https://app.geoguessr-waiwai.workers.dev/map-making-app-tools/privacy/)をご覧ください。


## ローカルインストール

開発者向けの手順です。一般利用は上記のChrome ウェブストアからのインストールをご利用ください。

```bash
git clone https://github.com/geoguessrwaiwai-lab/map-making-app-tools.git
cd map-making-app-tools
npm install
make unpacked
```

Chromeで`chrome://extensions/`を開き、「デベロッパー モード」を有効にしてから「パッケージ化されていない拡張機能を読み込む」で`dist/map-making-app-tools-unpacked`を指定します。

開発方針・フォーマット・検証・パッケージ作成など詳しい手順は[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。
