FEATURES

Small, focused, and privacy-friendly.

01

Resize by dragging

Place the pointer over the center divider and drag it left or right.

02

Limited to 25%–75%

The divider stays within a practical range so neither pane becomes unusably narrow.

03

Keyboard accessible

Focus the divider with Tab, then use the arrow keys, Home, or End.

04

Only runs in the editor

It activates only when a numeric /maps/ URL and the target editor grid are both present.

INSTALL

Install from GitHub

Until the extension is available in the Chrome Web Store, you can load it as an unpacked extension.

Download the source code ↓
  1. 1

    Extract the downloaded ZIP file.

  2. 2

    Open chrome://extensions/ and enable Developer mode.

  3. 3

    Select “Load unpacked” and choose the extracted folder.

  4. 4

    Reload the Map Making App editor page.

PRIVACY FIRST

We do not touch your data.

The extension does not collect, store, or transmit map data or browsing history. It uses no external requests, cookies, or analytics. Read the privacy policy.
