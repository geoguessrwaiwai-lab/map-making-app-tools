Privacy Policy

Last updated: August 5, 2026

Map Making App Tools (the “Extension”) does not collect, record, store, transmit, sell, or share personal information, map data, browsing history, cookies, or any other user data.

Pointer input

The Extension temporarily processes the pointer position in your browser while you drag the divider. This information is used only to calculate pane widths. It is not recorded, stored, or transmitted. The Extension does not read map content or form values.

Supported site

The Extension runs only on Map Making App editor pages whose URLs match https://map-making.app/maps/[number]. Even within the Manifest URL scope, it remains inactive unless both this URL format and the target editor element are present.

Network access and storage

The Extension makes no external network requests and uses no analytics, advertising, external JavaScript, cookies, or browser storage. It requests no extension permissions.

Third-party service

Map Making App is an independent third-party service. This unofficial Extension is not affiliated with, endorsed by, or connected to Map Making App or its operators.

Policy changes

If this policy changes, the latest version will be published on this page and the last-updated date will be revised.

Contact

For questions about the Extension, please visit the contact page.
