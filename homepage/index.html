FEATURES

必要な機能だけを、小さく安全に。

01

ドラッグで幅を調整

中央の境界線へカーソルを合わせ、そのまま左右へ動かせます。

02

25%〜75%に制限

片側が狭くなりすぎないよう、操作できる範囲を自動で制限します。

03

キーボードにも対応

Tabで境界線へ移動し、矢印キー、Home、Endでも調整できます。

04

編集画面だけで動作

/maps/数字のURLと対象グリッドが揃ったときだけ有効になります。

INSTALL

GitHubからインストール

Chrome ウェブストアで公開するまでは、パッケージ化されていない拡張機能として利用できます。

ソースコードをダウンロード ↓
  1. 1

    ダウンロードしたZIPを展開します。

  2. 2

    Chromeでchrome://extensions/を開き、デベロッパーモードを有効にします。

  3. 3

    「パッケージ化されていない拡張機能を読み込む」から、展開したフォルダを選びます。

  4. 4

    Map Making Appの編集ページを再読み込みします。
